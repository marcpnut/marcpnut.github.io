# LG webOS homebrew catalog

GitHub Pages serves the webOS app catalog at [`/repo`](https://marcpnut.github.io/repo) and [`/repo.json`](https://marcpnut.github.io/repo.json).

The catalog includes NextFlix, NightOwl, and NightOwly. NightOwl 0.3.14 tries provider streams directly and requests a server remux if playback fails. NightOwl's C9-compatible IPK and source are in [the NightOwl repository](https://github.com/marcpnut/NightOwl).


The webOS app asks for the server address during sign-in; this address is not stored in the repository or package.

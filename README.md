# LG webOS homebrew catalog

GitHub Pages serves the webOS app catalog at [`/repo`](https://marcpnut.github.io/repo) and [`/repo.json`](https://marcpnut.github.io/repo.json).

The catalog includes NextFlix and NightOwl. NightOwl's C9-compatible IPK and source are in [the NightOwl repository](https://github.com/marcpnut/NightOwl).
